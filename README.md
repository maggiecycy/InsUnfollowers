# Instagram Unfollowers

在浏览器里查看谁没有回关你。无需安装，脚本仅在本地运行。

## 使用

打开本仓库的 GitHub Pages，点击 **复制脚本**：

**https://maggiecycy.github.io/InsUnfollowers/**

然后到 [Instagram](https://www.instagram.com/) → 打开控制台 → 粘贴回车。

- Mac：`⌘ + ⌥ + I`
- Windows：`Ctrl + Shift + J`

请自行承担使用风险。

## 开发

```bash
npm install
npm run build-dev   # 本地预览
npm run build       # 更新 public/index.html 内嵌脚本
```

Node：见 `.nvmrc`。

基于 [davidarroyo1234/InstagramUnfollowers](https://github.com/davidarroyo1234/InstagramUnfollowers) fork。
